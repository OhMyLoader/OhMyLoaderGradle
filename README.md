# OhMyLoader Gradle Plugin

The `org.ohmyloader.gradle` plugin builds mods for
[OhMyLoader](https://github.com/OhMyLoader/OhMyLoader): it resolves the loader and game artifacts
by Maven coordinate, wires the mod's dependencies, and provides the `runClient` / `runServer`
tasks.
